This folder holds **project documentation** and the **Octa** web application.

## Canonical application

- **Path**: `stuff/Octa-758dd321db5a23889f15871624cfb035465e77ab/`
- **Stack**: Vite, React, TypeScript, Supabase (see that directory’s `README.md` and `package.json`).

From this directory:

```bash
cd stuff/Octa-758dd321db5a23889f15871624cfb035465e77ab
```
