# `cursor-brain/src/` — scratch only

**Production application code** lives in the repository root: **`src/`** (sibling of `cursor-brain/`, not inside it).

Use **this** directory for:

- Quick spikes, throwaway snippets, or experiments that should not ship in the main bundle.
- Files you plan to delete after a task.

For features users run in production, implement under **root `src/`** and follow `../patterns.md` and `../anti_patterns.md`.
