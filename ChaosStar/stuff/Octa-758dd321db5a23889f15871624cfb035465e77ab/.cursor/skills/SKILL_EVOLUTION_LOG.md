# Skill Evolution Log

Use this log to continuously improve project skills.

## How To Use
- Add one entry per major task or incident where a skill was used.
- Keep entries short and evidence-based.
- Review weekly and convert repeated issues into skill updates.

## Entry Template

```markdown
Date: 2026-04-14
Skill: <skill-name>
Task: <short description>
Outcome: success | partial | fail
Time Saved: <estimate>
Defects/Regressions: <none or list>
Missing Guidance: <what the skill did not cover>
Improvement Applied: <what was updated>
Next Review Date: <YYYY-MM-DD>
```

## Weekly Review Checklist
- [ ] Top used skills identified
- [ ] Low-success skills reviewed
- [ ] New recurring tasks without skills identified
- [ ] Deprecated/overlapping skills considered for merge
- [ ] Skill index updated if workflows changed
