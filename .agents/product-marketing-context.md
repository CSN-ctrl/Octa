# Product Marketing Context — Chaos Star / Sarakt Genesis

## Product

**Chaos Star Universe** is a persistent sci-fi economy MMO. **Sarakt Genesis** is the first playable world (Phase 1): users acquire land plots, hold in-game xBGL, and participate in an emerging landowner economy.

**Stack (Phase 1):** React web app, Supabase auth/ledger, Avalanche **Fuji testnet** (43113), on-chain land + treasury contracts.

## Ideal Customer Profile (Phase 1)

- Early adopters and crypto-native explorers comfortable with testnets
- Prospective landowners evaluating Genesis plot ownership
- Community members from Chaos Star / Sarakt lore and affiliate funnels

## Core Value Proposition

Own a plot in the Genesis world of Chaos Star — with on-chain proof, in-game currency (xBGL), and a path toward structures, rental income, and sovereignty in later phases.

## Phase 1 Scope (in)

- Email + wallet signup
- AVAX deposit on Fuji → xBGL credit
- Plot purchase on-chain
- Land title certificate
- Dashboard asset view
- Official docs (/docs)

## Phase 1 Scope (out / hidden)

- USDC mainnet deposit rail (legacy code gated)
- Nanofiber research, land-test, simulation mode (test routes)
- Digital ID, worker jobs, city/planet sovereignty purchases
- Celestial Forge premium assets in primary nav

## Activation Definition (Aha Moment)

User completes: **wallet connected → deposit credited → first plot purchased → certificate viewed**.

## Messaging Pillars

1. **Genesis ownership** — Limited Phase 1 plots; on-chain title
2. **Testnet safety** — Fuji only; no real money at stake in Phase 1
3. **Clear path** — Deposit → buy → certificate in one session
4. **Future economy** — Structures, rent, and sovereignty come later

## Pricing (Phase 1)

- Plot: 100 EUR equivalent in xBGL (~195.58 xBGL at current peg)
- Payment: AVAX on Fuji testnet via treasury deposit contract

## Primary URLs

- Production: https://www.sarakt.com
- Docs: https://www.sarakt.com/docs/getting-started

## Competitors / Alternatives

Not positioned against generic L2 games; differentiation is persistent world economy + hybrid on-chain land with Supabase game layer.

## Brand Voice

Confident, cinematic sci-fi, direct CTAs. Avoid over-promising Phase 2+ features in Phase 1 copy.
