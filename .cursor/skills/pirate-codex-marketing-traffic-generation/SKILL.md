# Pirate Codex Marketing - Traffic Generation Module

## Lessons
- Overview
- Channel Compass
- Campaign Structure
- Ad Creatives
- Explore & Scale
- Summary

## Workflow
1. Rank channels by fit, cost, and speed.
2. Define campaign naming and structure standards.
3. Build creative hypotheses and test matrix.
4. Run low-risk validation tests.
5. Scale winners with budget and stop-loss guardrails.

## Checklist
- [ ] Channel choices are evidence-based.
- [ ] Campaign structure is standardized.
- [ ] Creative tests isolate variables.
- [ ] Scaling rules include downside limits.
- [ ] Summary includes performance and next actions.

## Output Contract
Return:
1. Current lesson checkpoint
2. Channel and campaign decisions
3. Test results and scaling rules
4. Next lesson/task
