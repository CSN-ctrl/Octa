# Pirate Codex Build - Product Module

## Lessons
- Your Idea
- First Features
- Feature Planning
- Sprint Planning
- User Feedback
- Product Pricing

## Workflow
1. Define target user, problem, and desired outcome.
2. Choose MVP features and explicit non-goals.
3. Convert features into sprint-sized tasks.
4. Define feedback loops and success metrics.
5. Document pricing hypothesis and test plan.

## Checklist
- [ ] Problem and user segment are explicit.
- [ ] MVP scope is small and testable.
- [ ] Sprint plan includes dependencies and risks.
- [ ] Feedback channels and cadence are defined.
- [ ] Pricing test has success criteria.

## Output Contract
Return:
1. Current lesson checkpoint
2. Product decisions and assumptions
3. Validation plan
4. Next lesson/task
