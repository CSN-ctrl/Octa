# Pirate Codex Marketing - Funnel Building Module

## Lessons
- Overview
- Funnel Overview
- Landing Pages
- Messages
- CRM Workflows
- Summary

## Workflow
1. Map traffic source to conversion outcome.
2. Define funnel stages and transition criteria.
3. Align landing pages to intent segments.
4. Build stage-specific message variants.
5. Implement CRM automations and follow-up timing.

## Checklist
- [ ] Funnel stages are explicit and measurable.
- [ ] Landing pages match visitor intent.
- [ ] Messaging fits stage and objection profile.
- [ ] CRM automations have clear triggers.
- [ ] Summary includes funnel assumptions and risks.

## Output Contract
Return:
1. Current lesson checkpoint
2. Funnel decisions and rationale
3. Experiment and CRM plan
4. Next lesson/task
