# Pirate Codex Marketing - Content and Story Module

## Lessons
- Overview
- Why we do this
- What we talk about
- How we talk about it
- When we talk about it
- Summary

## Workflow
1. Define audience pain, promise, and positioning.
2. Choose content pillars and proof angles.
3. Set tone and voice boundaries.
4. Map messages by channel and audience stage.
5. Plan publishing cadence and quality gates.

## Checklist
- [ ] Narrative is specific and audience-first.
- [ ] Themes connect to product value and proof.
- [ ] Messaging is consistent across channels.
- [ ] Publishing plan is realistic and measurable.
- [ ] Summary includes expected awareness outcomes.

## Output Contract
Return:
1. Current lesson checkpoint
2. Messaging decisions and assumptions
3. Channel plan and cadence
4. Next lesson/task
