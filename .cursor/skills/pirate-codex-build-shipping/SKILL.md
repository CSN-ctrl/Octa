# Pirate Codex Build - Shipping Module

## Lessons
- Going Live
- Debugging Flow
- Git Workflow
- Preview & Production
- Debug Production
- Public Changelog

## Workflow
1. Prepare release checklist and rollback plan.
2. Ensure debugging flow is fast and repeatable.
3. Keep git/PR practices review-friendly.
4. Separate preview and production behavior safely.
5. Define production incident triage routine.
6. Publish clear user-facing change logs.

## Checklist
- [ ] Release checklist includes rollback criteria.
- [ ] Debugging workflow is documented.
- [ ] Branch and PR process is consistent.
- [ ] Preview/prod parity and separation are verified.
- [ ] Incident handling has owner and timeline.
- [ ] Changelog communicates impact clearly.

## Output Contract
Return:
1. Current lesson checkpoint
2. Shipping decisions and risks
3. Validation evidence
4. Next lesson/task
