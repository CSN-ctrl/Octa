# Pirate Codex Build - Design Module

## Lessons
- Landing Page
- UI Components
- Style Systems
- User Flow
- Mobile Responsive
- Purchase Experience

## Workflow
1. Define value proposition and first-screen message.
2. Standardize reusable UI components and tokens.
3. Map key user journeys and conversion friction points.
4. Validate responsive behavior on core breakpoints.
5. Optimize purchase flow states and clarity.

## Checklist
- [ ] Value is clear above the fold.
- [ ] Component reuse is preferred over one-off UI.
- [ ] Style system choices are consistent.
- [ ] User flow has clear next actions.
- [ ] Mobile and purchase paths are verified.

## Output Contract
Return:
1. Current lesson checkpoint
2. UX decisions and rationale
3. Validation evidence
4. Next lesson/task
