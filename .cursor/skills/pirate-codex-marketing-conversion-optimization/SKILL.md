# Pirate Codex Marketing - Conversion Optimization Module

## Lessons
- Overview
- Next Experiments
- Website Testing
- Email Testing
- Ad Testing
- Summary

## Workflow
1. Build experiment backlog using impact/confidence/effort.
2. Define baseline and success metrics per test.
3. Run website tests with controlled variants.
4. Run lifecycle email tests and compare cohorts.
5. Run ad tests with isolated variables.
6. Translate outcomes into next experiment cycle.

## Checklist
- [ ] Prioritization framework is explicit.
- [ ] Each test has baseline and success criteria.
- [ ] Test design minimizes confounding factors.
- [ ] Results include confidence and sample notes.
- [ ] Summary captures wins, losses, and follow-ups.

## Output Contract
Return:
1. Current lesson checkpoint
2. Test and optimization decisions
3. Results and confidence
4. Next lesson/task
