# Pirate Codex Marketing - Data Analytics Module

## Lessons
- Overview
- What we Measure
- How we Measure
- How we Report
- What to Improve
- Summary

## Workflow
1. Define metric taxonomy and event model.
2. Validate instrumentation coverage and quality.
3. Build reporting views tied to decisions.
4. Set reporting cadence and ownership.
5. Convert findings into prioritized experiments.

## Checklist
- [ ] Metrics have clear definitions and owners.
- [ ] Instrumentation accuracy is verified.
- [ ] Reports are actionable, not vanity.
- [ ] Improvement backlog is prioritized.
- [ ] Summary includes confidence and data gaps.

## Output Contract
Return:
1. Current lesson checkpoint
2. Metrics and instrumentation decisions
3. Reporting and experiment backlog
4. Next lesson/task
