# Pirate Codex Marketing

## Goal
Build a repeatable growth engine from strategy through conversion optimization with measurable checkpoints.

## Use This Skill When
- The user asks for go-to-market, acquisition, or conversion planning.
- Work needs structured progression from awareness to revenue.
- The team wants evidence-based marketing decisions, not ad-hoc tactics.

## Module Sequence
1. Growth Roadmap (Strategy)
2. Content and Story (Awareness)
3. Funnel Building (Acquisition)
4. Data Analytics (Measurement)
5. Traffic Generation (Growth)
6. Conversion Optimization (Revenue)

## Growth Roadmap Module
Lessons:
- Overview
- Where we AARRR
- Where the treasure lies
- How we get there
- Who is doing what
- Summary

Execution checklist:
- [ ] Define north-star metric and stage metrics.
- [ ] Map current funnel to AARRR stages.
- [ ] Pick highest-leverage bottleneck.
- [ ] Build strategy milestones with owners and dates.
- [ ] Assign ownership and operating cadence.
- [ ] Publish a concise strategy summary.

## Content and Story Module
Lessons:
- Overview
- Why we do this
- What we talk about
- How we talk about it
- When we talk about it
- Summary

Execution checklist:
- [ ] Clarify audience pain and promise.
- [ ] Define core content themes and proof angles.
- [ ] Set voice and narrative constraints.
- [ ] Build a channel-specific messaging matrix.
- [ ] Create publishing rhythm with quality gates.
- [ ] Summarize content strategy and expected outcomes.

## Funnel Building Module
Lessons:
- Overview
- Funnel Overview
- Landing Pages
- Messages
- CRM Workflows
- Summary

Execution checklist:
- [ ] Document awareness -> action journey.
- [ ] Define funnel entry points and CTA paths.
- [ ] Align landing pages to intent segments.
- [ ] Create message variants by funnel stage.
- [ ] Implement CRM automations for follow-up.
- [ ] Publish funnel assumptions and experiment queue.

## Data Analytics Module
Lessons:
- Overview
- What we Measure
- How we Measure
- How we Report
- What to Improve
- Summary

Execution checklist:
- [ ] Define event and metric taxonomy.
- [ ] Ensure instrumentation accuracy and ownership.
- [ ] Build reports for decisions, not vanity.
- [ ] Set report cadence and distribution.
- [ ] Convert findings into prioritized experiments.
- [ ] Summarize measurement reliability and known gaps.

## Traffic Generation Module
Lessons:
- Overview
- Channel Compass
- Campaign Structure
- Ad Creatives
- Explore and Scale
- Summary

Execution checklist:
- [ ] Prioritize channels by fit, speed, and cost.
- [ ] Standardize campaign structure and naming.
- [ ] Define creative hypotheses and test matrix.
- [ ] Run small-budget validation before scaling.
- [ ] Scale winners with guardrails and stop-loss rules.
- [ ] Summarize channel performance and next tests.

## Conversion Optimization Module
Lessons:
- Overview
- Next Experiments
- Website Testing
- Email Testing
- Ad Testing
- Summary

Execution checklist:
- [ ] Build hypothesis backlog ranked by impact/confidence/effort.
- [ ] Run website tests with stable success criteria.
- [ ] Run lifecycle email tests with holdouts where possible.
- [ ] Run ad tests with controlled variables.
- [ ] Track uplift with confidence and sample notes.
- [ ] Summarize wins, losses, and follow-up experiments.

## Output Contract
When this skill is used, return:
1. Current module and lesson checkpoint
2. Metrics and evidence reviewed
3. Experiments run or planned
4. Next action with expected impact

## Guardrails
- Strategy before tactics; do not scale unproven channels.
- Measurement before optimization; avoid decisions without baseline data.
- Keep experiment changes isolated to support causal attribution.
